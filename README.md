# Baan Hub Discord Bot (24/7 Member Counter & Honeypot)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/fast007x2-blip/baan-hub-bot)

Auto updates Discord member counts every 6 minutes and protects against spammers with real-time Honeypot.

### Environment Variables
- `BAAN_BOT_TOKEN`: Discord Bot Token
- `GUILD_ID`: Server ID (`1541653103982419988`)
- `ONLINE_CHANNEL_ID`: Online Members Voice Channel ID (`1544396402958925937`)
- `HUMANS_CHANNEL_ID`: Humans Voice Channel ID (`1544396405257412659`)
- `HONEY_CHANNEL_ID`: Honeypot Channel ID (`1544393321420558489`)
